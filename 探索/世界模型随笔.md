# 世界模型

## 1. SEM2

+ 序列模型中，先验作为上一帧到当前帧的推理，后验为获取传感器输入后的推理，训练时候用KL散度约束这连个的分布趋于一致；
+ Multi Source Samper：在采样器中从三个不同标注（如：碰撞、变道、直行）数据中抽取等量比例的数据组合成batch，缓解数据不平衡问题；

## 2. FIERY

+ 预测M个feature，训练时按照表现给予loss不同的权重；训练时，性能最好的头会以$1-\varepsilon$的权重反向传播，而其余头的权重为$\frac{\varepsilon}{M -1}$，实际训练中，取$M=10, \ \varepsilon = 0.05$。inspired by https://arxiv.org/pdf/1612.00197

## 3. MILE: Model-Based Imitation Learning for Urban Driving

+ 轨迹预测与世界模型：轨迹预测一般不关注环境的变化，只预测agents的未来轨迹；而world model不仅关注agents，也关注场景；
