## 一、 最新细节

1. 使用Group Normalization 代替 BN（目前看到在bev采样比较常用）：https://zhuanlan.zhihu.com/p/35005794 ， 几何采样用LN比较多

2. 使用SwiGLU代替Relu: https://zhuanlan.zhihu.com/p/31289994147
   + **门控机制**：通过Swish激活的权重动态调节信息流，过滤不重要信息， 相比传统FFN（ReLU + 线性层），能够通过门控减少冗余计算；
   + **平滑性/ 非单调性**：Swish的连续可导性缓解了ReLU的梯度消失问题，也允许模型捕捉更复杂的非线性模式， 平衡了非线性表达与梯度稳定性；
   + **参数效率**：相比ReLU, 避免ReLU的硬截断特性可能导致梯度消失；相比GELU，Swish的计算效率更高；

3. 使用Smooth Label技术：将硬标签（one-hot编码）转换为软标签，即为正确的类别分配一个稍小于1的概率，同时为错误的类别分配一个微小的概率，而不是直接将其置为0。适合数据量大且存在噪声的场景；

   + 使用了Label Smoothing损失函数后，在训练阶段预测正确时 loss 不会下降得太快，预测错误的時候 loss 不会惩罚得太多，使其不容易陷入局部最优点，这在一定程度可以抑制网络过拟合的现象。

   + 对于分类类别比较接近的场景，网络的预测不会过于绝对，在引入Label Smoothing技巧后，通过分配这些少数的几率也可以使得神经网络在训练的时候不这么绝对。

   + example：

     ```python
     import torch.nn as nn
     import torch.nn.functional as F
     
     class LabelSmoothingCrossEntropy(nn.Module):
         def __init__(self, eps=0.1, reduction='mean',ignore_index=-100):
             '''
             eps: smoothing rate
             reduction: 
             ignore_index: Specifies a target value that is ignored and does not contribute to the input gradient
             '''
             super(LabelSmoothingCrossEntropy, self).__init__()
             self.eps = eps
             self.reduction = reduction
             self.ignore_index = ignore_index
     
         def forward(self, output, target):
             '''
             output: model logits, shape=[batch, seq_len, dim]
             target: label squence, shape=[batch, seq_len]
             '''
             c = output.size()[-1]
             log_preds = F.log_softmax(output, dim=-1)
             if self.reduction=='sum':
                 smooth_loss = -log_preds.sum()
             else:
                 smooth_loss = -log_preds.sum(dim=-1)
                 if self.reduction=='mean':
                     smooth_loss = smooth_loss.mean()
     
             nll_loss = F.nll_loss(log_preds, target, reduction=self.reduction, ignore_index=self.ignore_index)
             return self.eps/c * smooth_loss + (1-self.eps) * nll_loss
     ```

4. Hinge Loss：Hinge Loss不仅要求模型正确分类样本，还要求置信度足够高，这意味着模型在正确分类的同时，预测值与真实值的差距要足够大。

5. 能用哈达马积（Hadamard Product， 即逐元素相乘）来融合特征，就不要用拼接或者相加，因为哈达马积可以引入更多非线性，并且还可以理解成一种滤波。pytorch中，只需使用常规的乘号操作符\*或torch.mul即可实现
